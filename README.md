# Clone TAB NEWS (Estudos)
Este projeto é um clone do TabNews com o objetivo principal de estudar e aplicar os conceitos apresentados no curso curso.dev do Filipe Deschamps.

🎯 Objetivo
O propósito deste repositório é recriar as funcionalidades e a arquitetura do TabNews original, servindo como um "clone de estudo". Ele é uma ferramenta prática para aprender sobre desenvolvimento web moderno, incluindo:

  - Back-end: Construção de APIs, autenticação, banco de dados (PostgreSQL), testes e segurança.

  - Front-end: Desenvolvimento com Next.js, React, consumo de APIs e estilização.

  - Infraestrutura: Conceitos de deploy, Vercel, e serviços web.

📖 Sobre o Curso
Este projeto segue a trilha de aprendizado do curso.dev, uma iniciativa de Filipe Deschamps onde ele constrói o TabNews do zero, de forma aberta e transparente.

Para acompanhar a construção original e ter acesso a todo o conteúdo, acesse: https://curso.dev
